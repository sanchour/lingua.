# Lingua's hand-drawn icons

Thirty-three icons on a 48 x 48 grid, drawn as in the Lingua Handbook (Part Three, "Icons: the Lingua hand"):
one fine line (`currentColor`, default soft ink), round caps and joins, and one terracotta detail (`#c86d51`).
Set `color` on the element to change the line, for example soft ivory `#bdb19f` and amber `#d49b54` in Nocturne.

They are not used by the app yet; the app's controls use Lucide. See the handbook for what each means and where it goes.
